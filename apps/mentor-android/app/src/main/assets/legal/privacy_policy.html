Privacy Policy

Last updated: September 2026

Lumina (Mentor) is a bring-your-own-key assistant. You choose which model providers to connect and which API keys to store on your device.

Data we store on your device

  • Chat history, skills, and usage statistics in a local SQLite database (Room) on your device.
  • API keys and tokens in Android encrypted storage (EncryptedSharedPreferences).
  • App preferences (theme, budgets, reminders) in DataStore.
  • Optional encrypted backup payloads you upload to a URL you configure.

Data sent to third parties

When you send a message, the app contacts the LLM provider you selected using credentials you supplied. We do not operate a central chat server.

Attachments: Images are resized on device and sent via your provider’s vision API when supported. PDF text may be extracted on device and included in the prompt.

Morning brief: Optional calendar reads (with permission), weather from Open-Meteo, and news from public RSS feeds when you enable those sections.

Optional features (encrypted backup, sync, ElevenLabs voice, Hugging Face search) only run when you configure them.

Backup and API keys

When backup includes API keys, they are encrypted before upload. A passphrase lets you restore on another device; without it, restore may work only on this device.

Permissions

  • Internet — model APIs, weather, news, optional sync/backup.
  • Microphone — voice input when you tap the mic.
  • Notifications — optional daily brief reminder.
  • Calendar — optional morning brief; event titles/times only when granted.
  • Biometric — optional app unlock.

On-device analytics (optional)

If you enable Help improve Discover in Settings, the app stores anonymous counts of which workflows and skills you use. Data stays on your device and is not uploaded.

Your choices

You can disconnect providers, clear credentials, disable backup/sync, and uninstall the app to remove on-device data. Backup is off by default.

Contact

For privacy questions, contact the developer listed on the app store listing.
