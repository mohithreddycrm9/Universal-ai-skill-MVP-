# Universal AI Skills — Privacy Policy

Publisher: CHALLA RAJA MOHITH REDDY

Published: 6 October 2026

Universal AI Skills is an independently authored package of instructions for compatible AI hosts. It contains no publisher-operated MCP server, account system, database, payment flow, analytics component, or telemetry component.

The package itself does not receive, store, sell, or transmit your conversations, credentials, files, or source code to the publisher. Your AI host and the tools you connect may process that information under their own policies and settings. This policy does not replace their policies or guarantee local-only processing.

The instructions restrict inspection to the codebase you authorize, require explicit approval before code changes, and prohibit external exports of codebase content or derived private information. They permit generic product, API, and version queries for official documentation. These are instructions for an agent; they are not a technical network block or a guarantee of host behavior.

The publisher provides support through the project's public GitHub issue tracker. If you choose to submit an issue, your GitHub account identity and the content you submit may be visible publicly and available to the publisher and other visitors. Do not include credentials, private code, personal information, or sensitive logs in an issue. Support information remains subject to GitHub's hosting, retention, and deletion controls; this package has no separate support database.

For privacy questions or requests concerning support content, use the issue tracker without including sensitive information. For conversations, connected-account data, or uploaded code processed by your AI host, use that host's privacy and deletion controls. The publisher cannot delete data held by an independent host through this instruction package.
